# Оформление вопроса ЧГК

Черновик материалов для будущего скилла `chgk-format`. SKILL.md ещё не написан.

---

## 1. Канонический формат

```
Вопрос N. [Раздаточный материал: …]
<текст вопроса>
Ответ: <то, что напишет большинство взявших команд>
Зачёт: <синонимы, варианты рода/числа, «по фамилии», «по упоминанию …»>
Незачёт: <только если частичный ответ имеет реальный шанс быть засчитанным>
Комментарий: <путь к ответу, понятный слабейшей команде; плюс интересное, что не вошло в текст>
Источник(и): <первоисточник на каждый факт вопроса; затем — на факты комментария>
Автор: Имя Фамилия (Город)
```

Проверки формата:
- Есть все поля. Комментарий и источник обязательны.
- Ответ — тот вариант, который напишет большинство, а не «точный, но редкий».
- Зачёт по смыслу допустим только с примерами; на синхронах его лучше избегать.
- «И похожие написания» в зачёте — красный флаг: возможно, спрашивается не то слово.
- Ударения в неочевидных словах и именах, «ё» везде, иностранные имена — с написанием в оригинале, указания ведущему — отдельно.

## 2. Комментарий

- Объясняет путь к ответу так, чтобы его поняла самая слабая команда, включая тонкие подсказки текста.
- Добавляет интересное, не вошедшее в вопрос. Пустых фраз («такое вот совпадение») нет.
- Не содержит информации, нужной для следующего вопроса: метавопросы по комментариям неуместны.
