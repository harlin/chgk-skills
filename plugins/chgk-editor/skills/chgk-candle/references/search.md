# Как работает поиск gotquestions.online

Проверено 2026-11-19 пятью запросами, по одному в минуту.

## Адрес и данные

- `https://gotquestions.online/search?search=<запрос>[&page=N]`. Страница рендерится на сервере, данные лежат в RSC-пейлоаде Next.js под ключом `"initialData"`: `{questions, highlights, total, page, pageSize, totalPages}`. Разбирает их `scripts/gq_search.py`.
- `pageSize` = 18. Порядок — по релевантности, не по дате.
- Каждый вопрос в выдаче полный: текст, раздатка, ответ, зачёт, комментарий, источники, `complexity` (процент взятия по отыгрышам), `tour.pack` (название, даты). Отдельно ходить на страницу вопроса не нужно.
- `highlights[id]` показывает, в каких полях найдено совпадение: `text`, `answer`, `zachet`, `comment`.

## Как понимается запрос

| Запрос | Результатов | Вывод |
|---|---|---|
| `тест` | 7712 | одно общее слово тонет в шуме |
| `Бакленд` | 14 | редкое имя — идеальный ключ; находит и «Ба́кленда» со знаком ударения и в другом падеже |
| `Бакленд копролит` | 2 | несколько слов — это **И**: остаются вопросы, где есть оба слова (в любых полях) |
| `Бакленд Джобс` | 0 | подтверждение И: слов вместе нет — пусто |
| `"тест ДНК"` | 5 | кавычки меняют поиск, но непредсказуемо: не нашёлся вопрос с «Тесты ДНК» в ответе. Кавычки не используй |

Следствия:
- словоформы и ударения поиск учитывает сам — пиши слово в любой форме;
- каждое добавленное слово сужает выдачу. Пара «реалия + ответ» даёт ответ почти наверняка, но если предшественник назвал реалию иначе, пара его потеряет. Поэтому реалию ищи и отдельно;
- ИЛИ нет. Варианты написания (Гёте / Гете) — отдельными запросами;
- поиск идёт и по комментарию, поэтому находка, которая есть только в комментарии старого вопроса, тоже находится.

## Не проверено

- Ищет ли поиск по тексту раздатки и по источникам.
- Есть ли фильтры (по дате, по полю). В интерфейсе их не видно.
- Сколько страниц выдачи можно получить без вреда. Мы берём одну, редко две.
